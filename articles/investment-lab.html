01 / GOAL

投资目标

投资首先服务于真实生活：保持财务安全、抵御通胀、让资本长期增长，并为未来几十年的自由生活提供现金流。

02 / PHILOSOPHY

投资哲学

不预测短期价格；理解资产背后的现金流、风险溢价和估值；用分散、低频再平衡和长期持有降低错误成本。

03 / DECISION

四层决策

第一层战略配置，第二层估值，第三层战术调整，第四层执行。越靠前越重要，越靠后越不能替代前面的判断。

04 / PROCESS

研究流程

提出问题 → 找数据 → 建模型 → 做历史回测 → 做压力测试 → 写下反方观点 → 形成执行规则 → 定期复盘。

05 / REBALANCE

再平衡

不依赖情绪决定买卖。设置目标权重和偏离阈值，用再平衡把市场波动转化为纪律化的低买高卖机制。

04

风险与反方

不仅问“为什么会涨”，更问“什么情况会证明我错了”。

THESIS 01

全球股票长期值得持有

反方：盈利增速下降、估值长期压缩或全球资本回报率结构性下降。

THESIS 02

黄金具有组合价值

反方：实际利率长期上升、风险溢价显著收缩，黄金机会成本持续抬升。

THESIS 03

中国红利适合防守

反方：股息持续下降、盈利恶化、监管或资本开支改变长期现金回报。

THESIS 04

长江电力适合长期研究

反方：ROE、自由现金流或电价机制发生结构性恶化，估值无法覆盖增长下降。

THESIS 05

中美不会轻易全面战争

反方：台海、南海或其他区域出现持续军事冲突。组合必须预先具备应对尾部风险的能力。

RISK 06

真正的最大风险

集中于单一国家、公司、货币或因子；以及在极端波动中临时改变长期规则。

05

研究工具

让观点逐渐变成可以计算、比较和验证的东西。

MODEL / 01

宏观状态模型

DXY、美国10年期国债收益率、实际利率、VIX、黄金、Brent、USD/CNY、CSI300估值、中国10年期国债、Fed Funds → 宏观状态识别。

MODEL / 02

投资决策引擎

把宏观状态、估值、风险与相关性连接到目标权重、当前权重和最终动作：BUY / HOLD / REDUCE / REBALANCE / WAIT。

MODEL / 03

历史回测

比较全球组合、沪深300、标普500、60/40、中国红利等策略的年化收益、最大回撤、夏普和恢复时间。

MODEL / 04

DCF / SOTP

用现金流、增长率、利润率、WACC 和终值估值公司；对复杂企业使用分部估值。

MODEL / 05

压力测试

测试衰退、通胀、利率冲击、汇率变化、股市大跌与地缘冲突等极端情景下的组合损失。

MODEL / 06

投资日志

每一次交易记录价格、金额、估值、投资逻辑、风险、持有期限和卖出条件，让未来的复盘有证据。

THE CORE IDEA

不是预测未来，而是让自己能够承受未来。

投资的真正目标不是每一年都赢，而是建立一个在不同经济周期、不同市场环境和不同人生阶段都能继续运行的系统。好的组合不要求知道明天发生什么，只要求在不知道未来的时候，仍然拥有足够的生存能力、增长能力和行动能力。
