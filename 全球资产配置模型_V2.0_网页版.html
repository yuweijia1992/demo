② Regime Engine — 全球宏观状态引擎

标准化得分 = 将各项指标映射到 0—100 的「金融条件紧张度」；加权分 = 标准化得分 × 权重 ÷ 100；综合压力分数为八项加权分之和。

③ Asset Score — 资产评分引擎（0—100）

综合评分 = 五个维度得分的算术平均，仅用于目标仓位倾斜，不代表预期收益率。

④ Allocation — 目标仓位引擎

「当前权重」列为你的实际持仓，可直接修改（假设各资产内部无二次偏离）。目标权重 = 基准权重 + 评分倾斜（倾斜幅度限制在 ±5%）。

使用顺序与模型边界

  • 使用顺序：①更新 Macro Inputs → ②查看 Regime Engine → ③查看 Asset Score → ④查看 Allocation（填写当前权重）→ ⑤查看 Scenario → ⑥执行 Rebalance
  • 重要说明：本模型是规则化资产配置工具，不是收益预测器；情景收益为参数假设，可自行修改。黄色单元格/输入框为用户输入，其余均为公式实时计算结果。
  • 默认组合：全球股票 30% / 中国股票 15% / 美债 15% / 中国债 10% / 黄金 10% / 现金 10% / REITs 5% / 机会仓 5%。
  • 执行纪律：不要因单日市场波动频繁交易；优先用新增资金、现金流和到期资金完成再平衡。
  • 模型边界：本页为离线单文件规则引擎，不会自动联网抓取行情；如需自动更新，可接入数据 API 并增加历史分位数、滚动均线与数据校验。
