# 49家公司估值模型数据库

本目录由 `scripts/build_valuation_model.py` 自动生成。

## 输入
- `data/china-stocks-financial-valuation.json`：公司主证券、行业分类与基础信息。
- `data/financial-standardized/company-financials-2021-2025.json`：2021—2025年标准化财务数据。
- `data/valuation-history/generated/valuation-monthly.csv`：月度PE/PB/PS历史估值。
- `data/valuation-model/issuer-report-index-49.json`：49/49家公司已定位官方年度报告入口（48家FY2025年报、阿里巴巴FY2026年报）；半年报和三季报另行记录，报告链接定位不等于内容核验。
- `data/valuation-model/issuer-verification-evidence.json`：逐项人工报告核验档案。

## 输出
- `valuation-model-49.json`：49家公司年度财务派生指标、历史估值分位、五年机械情景预测、公司级估值驱动模板和质量状态。
- `valuation-model-audit.json`：覆盖数量、严格连续窗口分位覆盖、来源核验状态和限制。
- `valuation-verification-register-49.json`：逐家公司核验状态、来源链接、行业假设模板和每股估值放行状态。
- `issuer-report-index-49.json`：官方报告定位结果。链接定位不等于内容核验。

## 计算口径
1. ROE = 归母净利润 / 年初、年末归母权益平均值。缺少任一期权益则留空。
2. 简化FCF = 经营活动现金流净额 - 购建固定资产、无形资产和其他长期资产支付的现金。它不是股权自由现金流；金融机构不使用普通企业FCF。
3. 完整净债务 = 短期借款 + 短期应付债券 + 一年内到期长期债务 + 长期借款 + 应付债券 + 流动及非流动租赁负债 - 单独识别的现金及现金等价物。不得直接用可能包含受限资金的货币资金总额抵扣；任何债务组成项或现金等价物缺失时留空；金融机构不适用。
4. ROIC近似口径：NOPAT = 营业利润 × (1 - 所得税费用/利润总额)；投入资本 = 总资产 - 非付息流动负债 - 现金及现金等价物 - 短期投资 - 长期投资；非付息流动负债 = 流动负债 - 明确列示且包含于流动负债的短期借款、短期债券、一年内到期长期债务和流动租赁负债。长期借款、长期债券和非流动租赁负债不重复加回。平均投入资本采用期初期末平均；缺少任一关键输入、税率异常或投入资本非正时留空。该指标仍须逐项年报核验。
5. 现金及现金等价物优先取资产负债表明确列示值；缺失时可使用现金流量表期末现金及现金等价物余额。受限货币资金不能默认视为可抵扣现金。
6. 历史估值的5年/10年分位要求连续60/120个自然月每个月均有有效正值；负PE、缺月不插值。
7. 公司级估值驱动模板按公司和行业区分券商、半导体、医药医疗、数字平台、银行、保险、周期制造和公用事业。模板列出量价、良率、产能利用率、研发、资本开支、ROE/资产质量、NBV/偿付能力等必要输入；参数默认留空，必须由公司公告、运营数据和估值日市场数据支持。
8. 五年预测仍为机械情景参考：基准收入增长率取历史CAGR，净利率取最近三年中位数；悲观/乐观情景作固定百分点扰动，不代表公司指引或分析师共识。
9. 股本字段保留财报原值；归母净利润/稀释EPS得到的仅是年度加权平均股数代理，不是估值日当前完全稀释股数。现金流中的股利与利息合并支付不能当作纯股息。
10. 不输出每股内在价值或买入评级，除非币种、金额单位、完全稀释股数、报告期和估值日股价经过独立核验。缺失值保持null。

## 当前核验状态
接口抓取、字段映射和公式计算不等于发行人年报核验。当前已有伊利股份、申洲国际两家公司官方年度报告的部分字段交叉核验。申洲国际另核验了2026-05-27股东周年大会/末期股息公告。其余47家公司仍须逐家核对报告正文、审计意见、合并范围、币种单位、债务、股本、股息和资本配置。官方报告链接定位率为49/49；报告内容部分核验率为2/49，二者严格分开。

## 官方报告来源
A股报告链接由巨潮资讯公告检索接口定位；港股报告链接来自HKEXnews、发行人投资者关系网站或SEC/20-F法定文件。官方链接只证明来源可追溯，不代表字段已经逐项核验。
