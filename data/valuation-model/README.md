# 49家公司估值模型数据库

本目录由 `scripts/build_valuation_model.py` 自动生成，输入为：

- `data/china-stocks-financial-valuation.json`：49家公司主证券、行业模型分类及交易数据快照；
- `data/financial-standardized/company-financials-2021-2025.json`：2021—2025年标准化财务数据；
- `data/valuation-history/generated/valuation-monthly.csv`：月度PE/PB/PS历史观测。

## 输出

- `valuation-model-49.json`：49家公司逐年财务派生指标、历史估值分位、五年机械情景预测和质量状态。
- `valuation-model-audit.json`：覆盖数量、严格连续窗口分位覆盖及限制。
- `valuation-verification-register-49.json`：49家公司逐项核验清单、来源类型、公司特定假设状态及每股估值放行状态。
- `issuer-verification-evidence.json`：人工逐项对照发行人年报的证据档案；目前伊利股份2025年报为部分交叉核验，其余公司仍待核验。

## 计算口径

1. ROE = 归母净利润 / 年初、年末归母权益平均值。2021年缺少2020年末权益时不计算。
2. 简化FCF = 经营活动现金流净额 - 购建固定资产、无形资产和其他长期资产支付的现金。金融机构不使用普通企业FCF。
3. 净债务 = 短期借款 + 长期借款 + 应付债券 + 流动租赁负债 + 非流动租赁负债 - 现金。只有全部债务分项和现金均有数据才计算；金融机构不使用该普通企业指标。
4. ROIC近似口径：NOPAT=营业利润×(1-所得税费用/利润总额)；投入资本=总资产-流动负债+全部已映射有息债务-现金-短期投资-长期投资；分母采用期初期末平均。只有全部组成项可得时才计算，仍须逐项与年报核验；该近似口径未完成商誉、少数股东权益、联营投资和租赁会计的全行业统一调整。
5. 历史估值最新值使用每证券每自然月最后一条有效记录。5年/10年分位分别要求连续60/120个自然月每个月都有有效正值；负PE、缺月不插值。
6. 公司级假设模板按估值模型分类提供量价、利润率、资本开支、周期、ROE/资产质量、NBV/偿付能力等输入项；参数默认留空，必须由公司公告、行业运营数据和估值日市场数据支持。五年预测为机械情景参考：基准收入增长率取2021—2025可得收入序列CAGR；基准净利率取最近三年中位数。悲观/乐观分别对收入增速±5个百分点、净利率±1.5个百分点；非金融企业FCF利润率±3个百分点。它们不是公司指引或分析师一致预期。
7. 股本字段只保留财报原值；净利润/稀释EPS得到的仅是年度加权平均稀释股数代理，不是估值日当前完全稀释股数。现金流中的股息支付不等于逐年每股股息历史。
8. 不输出每股内在价值或买入评级，除非交易币种、源金额单位、完全稀释股数及报告期间都经过独立核验。缺失值保持null。

## 数据状态

接口抓取或字段映射不等于独立核验。来源原值、派生指标、机械预测和待核验字段应分别理解。A/H双重上市财报不合并，金额不跨币种或单位直接比较。

## 自动化

GitHub Actions 工作流：`.github/workflows/build-company-valuation-model.yml`。当模型脚本、财务标准化文件、月度估值库或估值引擎页面更新时自动重建并校验49家公司记录。

逐家公司核验页面：`articles/company-verification.html`。当前财务来源多数为二手数据平台转载/结构化接口；即使公式已算出，未与交易所或发行人正式年报逐项勾稽前，状态仍为待核验。

逐家公司核验工作台：`articles/company-verification.html`。目前伊利股份FY2025已对收入定义、利润、现金流、资产负债、股本、EPS和分红预案等部分项目完成报告文本交叉对照；官方IR页面提供年报PDF入口，但本轮使用的可检索全文为报告文本镜像，故状态仍是“部分交叉核验”，不标记为全量官方核验。其余48家公司尚未完成逐项年报勾稽。
