# 49家公司财务数据采集流水线

## A股采集
运行 `python scripts/collect_financial_statements.py`，通过 AKShare 的 `stock_financial_report_sina` 获取新浪财经披露的资产负债表、利润表、现金流量表。每次原样保存供应商字段、报告期字段、来源链接、抓取时间、行数、错误和 SHA-256。

## 边界
- 本流水线目前只自动采集主数据库中可识别的 A 股代码。双重上市公司仅采集A股代码，不把A股数据复制到港股证券。
- 港股主上市及独立港股股份类别必须从 HKEXnews/公司公告提取并独立存档。
- 原始接口行先归档，不自动猜测字段映射；字段映射经核验后才能计算ROIC、净债务、稀释股数或TTM。
- 半年/季度利润表、现金流量表的累计数不是单季数。TTM须按同口径“最近完整年度 + 本年累计 - 上年同期累计”计算，并处理会计政策、币种、合并范围及报告重述。
- 金融企业（银行、保险、券商）不套用普通工商企业的FCF/净债务/ROIC模板。

## 运行
GitHub Actions 可手动触发，也设置为每月5日UTC 02:30自动归档。运行失败或某公司无数据会写入错误/空记录，不得视为已补齐。
