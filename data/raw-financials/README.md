## 采集来源与期间口径

### A股

通过 AKShare 调用新浪财经财务报表数据，按主数据库中44只A股代码收集资产负债表、利润表、现金流量表。每只证券保存原始字段、报告日期、币种、审计标记、公告日期、数据源、抓取时间与请求状态。

### 港股

通过 AKShare 所封装的东方财富港股财务数据通道，按13个港股代码分别获取三大报表，并分别保留：
- 年度模式：年度报告期序列；
- 报告期模式：年度、中期及季度/累计报告期序列。

港股主上市及A/H双重上市公司的港股代码分别存档。ADR参考代码不自动视为独立财报来源；不得把ADR价格、港股价格和A股每股指标拼接。

## 数据边界

- 本目录是原始财务数据归档，不是经审计的统一财务数据库。采集请求成功仅代表接口返回了记录，不代表每一条原始数值都已与发行人正式年报复核。
- 原始接口行先归档，不自动猜测字段映射。字段映射经核验后才能计算ROIC、净债务、稀释股数或TTM。
- A股Sina/AKShare字段与港股Eastmoney/AKShare字段结构不同。标准化时必须保留币种、金额单位、报告期、财年、合并范围和原始项目代码。
- 半年/季度利润表、现金流量表的累计数不是单季数。TTM须按同口径“最近完整年度 + 本年累计 - 上年同期累计”计算，并处理会计政策、币种、合并范围及报告重述。
- 年度报告、半年报告、季度报告分别保留原始披露期间；不得将半年数直接乘以2作为全年预测或TTM。
- BVPS需使用归母权益及相应期末股本，并考虑送转、增发、回购、股权激励和稀释；不能只使用数据库中的单期快照。
- 股息、股本变化、回购与完全稀释股数需从公告/股本及分红数据另建历史表；当前三大报表采集完成不等于这些项目已完整归档。
- 资本开支需从现金流量表购建固定资产、无形资产和其他长期资产支出提取，并区分收购支出、处置、资本化开发支出和维护/扩张用途。
- 金融企业（银行、保险、券商）不套用普通工商企业的FCF/净债务/ROIC模板。
