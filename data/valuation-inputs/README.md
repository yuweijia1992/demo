# 49家公司估值输入补齐规范

生成日期：2026-10-31  
底稿：`data/valuation-inputs/valuation-input-audit-49.json`

## 当前状态

该文件是逐家公司数据缺口审计底稿，不是已完成估值。49家公司当前主表以单期财务快照为主，不能据此推导完整历史序列、TTM现金流或五年预测。

## 必须遵守的数据口径

1. **历史序列**：优先收集2021—2025年度合并报表，并保留报告期、公告日、币种、单位、审计状态和原始来源。周期企业尽可能延伸至完整周期。
2. **TTM**：对截至2026H1的指标，原则上使用2025全年 + 2026H1 - 2025H1。若会计口径、合并范围、币种或报告期不一致，不得机械拼接。
3. **FCF**：经营现金流减购建固定资产、无形资产及其他长期资产支付的现金。另行标注并购、处置、资本化开发支出、租赁付款等可能影响现金流可比性的项目。此简化口径不等同于严格FCFF。
4. **ROIC**：NOPAT / 平均投入资本。必须记录税率、平均资产负债表口径、商誉、租赁负债、联营投资和金融资产的处理方式。
5. **ROE**：报告期加权平均ROE与长期可持续ROE分开保存；后者须结合盈利周期、杠杆、资本约束和留存收益回报判断。
6. **资本成本**：记录估值日、无风险利率期限与币种、Beta来源/窗口/频率、股权风险溢价来源、税前债务成本、税率和资本结构。参数不能无日期地永久沿用。
7. **稀释后股数**：区分期末股本、加权平均基本股数、完全稀释股数；检查可转债、期权、限制性股票、增发、回购及港股不同类别股份。
8. **情景预测**：五年逐年预测收入、利润率、税率、再投资、FCF和股数；悲观/基准/乐观情景逐项记录依据与来源。不得只保存最终估值。
9. **币种**：A/H双重上市公司分别保留上市证券价格、每股指标和货币单位；跨币种估值需保存汇率日期和来源。
10. **金融企业**：银行/券商不套用普通企业FCF和净债务公式；保险公司NBV、VNB、内含价值需核对是否存在重复计价。

## 行业模型的最低输入

- 成熟制造/消费：正常化EPS、TTM股权FCF、ROIC、再投资率、WACC/股权成本、合理估值倍数。
- 成长企业：五年收入增长、FCF利润率、税率、再投资、折现率、终值增长率和完全稀释股数。
- 银行：可持续ROE、股权成本、长期增长率、BVPS、资本充足率、不良率和拨备覆盖率。
- 保险：每股NBV、VNB、新业务价值倍数、内含价值口径、偿付能力和业务结构。
- 周期企业：至少一个完整周期的价格/销量/成本/产能利用率/资本开支/负债与正常化利润。

## 状态定义

- `verified`：原始公告或可靠原始数据已核验，口径和计算可复现。
- `derived`：由已核验原始数据计算，保存公式和输入引用。
- `estimated`：分析假设，不得混同事实数据；必须有理由、来源和敏感性。
- `pending`：缺数据或口径未解决。
- `not_applicable`：该指标对该行业不适用，并说明原因。

缺失值保持 `null`，不得用0、行业均值或网页默认值填充。
