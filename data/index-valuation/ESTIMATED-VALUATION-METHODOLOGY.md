# 纳指100与恒生指数估值估计层（模型值，非真实观测）

生成脚本：`scripts/build_estimated_index_valuation.py`

## 为什么另建估计层

纳指100与恒生指数目前没有可合法公开再分发、口径一致且连续覆盖5—10年的PE/PB月频原始序列。免费估值快照数量不足，不能据此宣称得到真实历史分位。

因此本项目新增独立的**模型估计层**，用于研究和日常监控的暂代输入。它不覆盖、不修改 `valuation-monthly-partial.csv` 中的真实观测数据，也不将估计值伪装为供应商历史报价。

## 估算方法

对每个指数、每个月：

`估计PE_t = PE锚点 × (指数价格代理_t / 锚点月份指数价格代理) / (1 + EPS增长假设)^(月份差/12)`

`估计PB_t = PB锚点 × (指数价格代理_t / 锚点月份指数价格代理) / (1 + 净资产增长假设)^(月份差/12)`

指数价格优先使用 Yahoo Finance 的 `^NDX` 和 `^HSI`。本轮实际审计发现，接口全历史响应并非连续月频，早期序列约每三个月才返回一个点。为满足月度操作界面，脚本保留接口原始点，并对点位间缺失月份按价格的对数线性方式插值；每个月逐行标记为“接口返回点”或“区间插值估计”。若直接指数接口不可用，才分别退回 `QQQ` 和 `2800.HK` 未复权收盘价作相对价格代理。这里生成的完整月度估值路径因此是模型估计，不是实际月频行情与估值。

## 当前锚点及参数

估值锚点取仓库 `public-valuation-snapshots.csv` 中最近31天内同一指数/指标快照的中位数。供应商之间口径不同，保留各条原始锚点并以最小值/最大值构成来源包络。

- 纳指100 PE-TTM：快照包括 Guchacha 26.97、WorldPEratio 的 QQQ NAV 代理29.83、Siblis 32.76；中心锚点为中位数29.83。由于供应商口径不完全一致，来源包络不是统计置信区间。
- 纳指100 PB：Guchacha快照8.43；单一快照使用±15%模型包络。
- 恒生PE-TTM：Guchacha快照10.80、10.93；中心锚点10.865。
- 恒生PB：Guchacha快照1.14、1.15；中心锚点1.145。

恒生和纳指的基准增长假设：

| 指数 | PE的年化EPS增长（低/基准/高） | PB的年化净资产增长（低/基准/高） |
|---|---:|---:|
| 纳指100 | 9% / 12% / 15% | 7% / 10% / 13% |
| 恒生指数 | 3% / 5% / 7% | 3% / 5% / 7% |

以上增长率是模型参数，不是已经核实的指数历史EPS/BVPS增长率。修改参数即可重建整条估计序列。

## 输出文件

- `ndx-hsi-price-proxies-monthly.csv`：行情价格代理、代码、来源、月份及原始点/插值质量标记。
- `ndx-hsi-estimated-monthly.csv`：估计PE/PB中心值、低/高情景包络、锚点、增长率及模型内部5年/10年估计分位。
- `ndx-hsi-estimated-audit.json`：模型状态、覆盖日期、锚点来源、参数、置信度和错误记录。

估计分位至少需要60/120个模型月份，分别对应5年/10年；中间月份若来自插值，分位数也包含插值路径。因此它们仅是模型路径内部的估计分位，不是真实观测分布，也可能低估实际月度波动。结果用于监控和情景比较，不应单独触发买卖或改变战略资产配置。

## 重要局限

1. 没有重建历史指数成分股、历史权重、历史财报、回购、减值和会计口径变化。
2. 恒定EPS/BVPS增长假设无法描述盈利周期和资产负债表结构变迁。
3. 纳指不同供应商的PE快照差异较大；PB存在单一来源快照问题。
4. ETF价格代理会有费用、跟踪误差和分红处理差异。
5. 估计区间是参数与锚点情景包络，不是概率区间。
6. 页面必须始终显示“模型估计”，不得称为历史真实PE/PB。

自动工作流每月更新公开行情代理、生成模型序列和审计文件。获取许可数据后，可直接用实测月频序列替换模型估计层，而不破坏原始数据和审计链。
