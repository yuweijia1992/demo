# V1.2 示意成果包（非正式数据）

> 状态：示意模板。此目录不包含经过下载和审计的真实历史数据，不得用于计算风险分数、回测或投资决策。

## 本示意包包含

- `monthly-panel-demo.csv`：月度统一面板的字段结构。示意月份行中的所有数值均为 `NA`，不是实际观测。
- `source-coverage-demo.csv`：六项原始数据源的覆盖与验收状态登记表。
- `audit-demo.json`：机器可读的审计摘要结构。

## 缺失值规则

1. 不插值、不前向填充、不用其他频率数据伪造月频值。
2. 未下载、下载失败、格式不符、尚未核验分别记录，不混为一个“缺失”状态。
3. FRED 当前修订序列标记为 `CURRENT_REVISED_NON_PIT`，不得当作历史时点可得数据。
4. NFCI vintage 必须按历史可得版本匹配；没有对应 vintage 时保留空值并标记原因。
5. SHA256 只有在原始文件真实落盘后计算；未取得文件时写 `null`，不得填占位哈希。
6. 只有原始文件、覆盖范围、异常值、哈希、日期对齐和 PIT 属性全部核验后，才可将该数据源标记为 PASS。

## 正式数据目录约定

正式原始文件和正式审计输出仍由 V1.2 工作流写入本目录的上一级 `data/index-valuation/`，本示意目录与正式数据隔离，避免将模板误认为真实数据。

## 当前限制

本示意包不声明任何真实数据行数、起止日期、缺失率、异常值数量或 SHA256。正式结果以工作流生成的原始文件和审计 JSON 为准。
