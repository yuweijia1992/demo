# 标准化财务数据库（2021—2025）

本目录由 scripts/standardize_financial_statements.py 从 data/raw-financials/ 的最新原始归档生成。

## 文件

- company-financials-2021-2025.json：49家公司的主上市证券年度序列、TTM结果和A/H其他上市地独立序列。
- standardization-audit.json：逐公司覆盖、五年关键字段完整度、TTM状态。
- hk-item-map-audit.json：港股长表项目名称与代码映射审计。

## 当前覆盖（以审计文件为准）

- 49/49家公司完成主上市证券档案标准化。
- 2021—2025年收入及归母净利润关键字段：49/49家公司五年完整。
- 2021—2025年总资产及归母权益关键字段：49/49家公司五年完整。
- 2021—2025年经营现金流及资本开支：48/49家公司五年完整；阿里巴巴2021财年资本开支分项不完整，保留缺失，不补零。
- A股44/44家公司已按 FY2025 + 2026年累计值 - 2025年同期累计值 生成收入及归母净利润TTM；非金融企业另外计算经营现金流与资本开支TTM。港股5家主上市公司因财年结束月份不同，TTM暂不按自然年机械拼接。

## 重要口径

1. A股与港股长表采用不同字段结构。港股按 REPORT_DATE + STD_ITEM_NAME + AMOUNT 还原为宽表。
2. A/H双重上市的报表分别存放；主序列按主数据库证券代码中的第一个上市代码选择，不把A股和H股数据混合。
3. 原始金额保留来源数值和币种/单位元数据；没有明确披露单位时不猜测、不换算。不能直接跨公司比较原始金额。
4. 原始数据来自新浪财经/AKShare（A股）及东方财富港股/AKShare（港股）。接口成功返回不等于已与发行人年报逐项复核。
5. 简单字段映射标记为 pending（来源已抓取但尚未独立核验）；由公式计算的字段标记为 derived；缺失字段保持 null。不得把抓取状态等同于 verified。
6. TTM仅在同一证券、同一会计口径、同一币种及同一累计期间可以对齐时计算。金融企业不使用普通企业FCF作为核心估值输入。
7. 不在本批次计算ROIC、净债务、完全稀释股数或每股目标价；这些指标仍需额外核验债务、租赁、资本结构、股本和公司公告。
8. 五年预测在网页端由用户编辑假设生成，标签为 estimated，不是公司指引或分析师共识预测。
