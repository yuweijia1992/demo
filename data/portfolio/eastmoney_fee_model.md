# 东方财富证券账户费用估算与组合执行成本模型

版本：2026-11-12  
用途：用于400万元长期组合的研究预算，不代表东方财富证券对该账户的实际报价。

## 1. 基准假设

| 项目 | 估算值 | 说明 |
|---|---:|---|
| ETF场内买卖佣金 | 成交金额的0.03%（万3） | 暂按偏保守研究预算参数估算，须以账户交割单/费用说明为准 |
| 单笔最低佣金 | 5元 | 保守估算；部分账户或品种可能不同 |
| 印花税 | ETF二级市场买卖按0估算 | 股票印花税规则不直接套用到ETF |
| 基金管理费/托管费 | 按每只基金合同 | 从基金资产中计提，已反映在净值，不是下单时另扣佣金 |
| 买卖价差 | 不预设固定值 | 下单前查看盘口，尽量使用限价单 |
| QDII场内溢价 | 不计入手续费，单独控制 | 溢价扩大可能远超佣金成本 |

注意：沪深交易所ETF竞价交易存在交易所经手费规则，部分债券ETF、货币ETF有暂免安排；投资者实际看到的费用如何在券商佣金中体现，以券商交割单和收费公示为准。不得在佣金之外重复加计交易所费用，除非交割单明确分项收取。

## 2. 费用公式

单笔场内交易估算：

`佣金 = max(成交金额 × 0.0003, 5元)`

若账户实际没有5元最低收费，则将最低值改为0；若实际佣金率不同，则替换0.0003。

## 3. 400万元组合的成本量级

- 一次性买入400万元：按万3估算约1,200元；若分多笔且触发最低收费，费用会略高。
- 未来全部卖出400万元：按相同成交金额估算约1,200元；实际取决于卖出时市值和账户费率。
- 一次性买入再全部卖出的双边佣金基准约2,400元，约占400万元的0.06%；不含基金内部年费、买卖价差、QDII溢价/折价和税务等其他影响。
- 若年度实际成交总额（买入额+卖出额）为40万元，佣金约120元；若年度双边成交总额为80万元，佣金约240元。这里按成交总额计费，不把“换手率”与买卖双边混淆。

## 4. 组合分批建仓估算

对400万元组合分6个月分批建仓，若每月约投入总额的六分之一，累计成交额仍约400万元。按比例佣金仍约1,200元；最低收费可能使费用小幅增加。实际应按每一笔委托单计算，避免把同一产品拆成大量小单。

未找到合格产品的海外市场袖套和债券袖套，不得为了凑齐400万元而买入不匹配产品。现金暂留银行存款/货币工具，直至合格产品完成尽调。

## 5. 执行步骤

1. 东方财富APP搜索产品代码，确认基金全称、上市状态、买卖按钮和风险提示。
2. 下单前查看实时IOPV、场内价格、溢价率、买卖价差、成交额及最新公告；QDII溢价超过3%暂停追买，超过5%不追价（本项目研究纪律，不是交易所法定阈值）。
3. 优先使用限价单，避免开盘初段、临近收盘和盘口稀薄时追价。
4. 首次只做小额验证单，成交后核对交割单佣金、最低收费和是否另收其他项目。
5. 把实际费率写回本文件和回测参数，再执行后续批次。
6. 申购赎回资格与场内买卖分开核验；不能因可交易就假设可申赎。

## 6. 交易权限与产品状态

- 普通A股证券账户通常可以交易ETF；上交所说明股票ETF通常T+1，部分债券、黄金、跨境和货币ETF可T+0，但具体以产品规则为准。
- 具体基金能否在东方财富账户交易、是否暂停申购、是否有临时停牌，必须在下单当日核验。
- 本文不声称已读取用户账户权限或个性化费率。
