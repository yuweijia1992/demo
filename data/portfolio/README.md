## 尚未批准的关键参数

1. 股票52%内部：A股、港股、美国、其他发达市场、新兴市场各占多少。
2. 债券28%内部：中国/海外、国债/政策性金融债/信用债、期限结构与汇率对冲比例。
3. 各袖套最终采用的真实可购买基金/ETF/指数产品。
4. 再平衡周期、触发阈值、现金流优先规则。
5. 实际账户佣金、税费、基金费率、汇兑点差及产品流动性。

## 数据库表

- data/portfolio/portfolio_policy.json：政策总表、已确认权重、审批状态与硬性约束。
- data/portfolio/portfolio_sleeves.csv：资产袖套与实际产品主数据；未确认权重和产品字段保持空白。
- data/portfolio/execution_rules.json：再平衡与下单控制规则；候选规则不自动视为已批准。
- data/investment-monthly.csv：原始月度数据矩阵。
- data/investment-monthly-manifest.json：数据来源、覆盖与刷新状态。
- data/research/monthly_coverage_audit.csv：逐字段缺失审计。

## 产品入库验收字段

产品代码、交易所/平台、基准指数、复制方式、分红处理、成立日期、规模、综合费率、买卖价差、跟踪误差、交易单位、申赎规则、账户可交易性、税务处理、币种与对冲方式、数据来源、最近核验日期。

## 正式启用条件

只有当总权重校验通过、内部权重获批、产品尽调完整、数据口径可追溯、账户交易条件核实、再平衡规则获批后，状态才可从 BLOCKED_PENDING_POLICY_APPROVAL 改为 APPROVED_FOR_EXECUTION。研究代理回测不得替代产品真实净值回测。
