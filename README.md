**GitHub 仓库：** https://github.com/yuweijia1992/demo

## GitHub Pages

本项目为纯静态网站，无需 Node.js 或构建工具。进入仓库 Settings → Pages，在 Build and deployment 中选择 Deploy from a branch，Branch 选择 `main`、目录选择 `/ (root)` 后保存即可。
