# V1.2 → 五因子严格点时模型重建规范

状态：实施规范；不是已完成的数据交付，也不是回测结果。

## 目标

将 `articles/sp500-valuation-macro-full-model-demo.html` 从静态示意页升级为读取真实、可复算数据的研究页面。任何历史因子值都必须来自当月投资者当时已经能够获得的信息集。

## 五因子与信息集

| 因子 | 目标输入 | 频率处理 | 严格 PIT 必需条件 |
|---|---|---|---|
| CAPE 估值 | Shiller/CAPE 月度值及历史发布档案 | 月度 | 保存每期首次发布日期/可用日期或历史 vintage；仅有今天下载的回溯序列不合格 |
| 10年实际利率 | DFII10 | 日频聚合月均 | 使用 ALFRED vintage 或可验证的实时发布档案；按发布日期滞后 |
| NFCI | Chicago Fed NFCI | 周频 | ALFRED vintage；每个信号日只能取当时已发布的最近一期 |
| 政策利率水平 | FEDFUNDS | 月频 | FOMC/官方发布日历或 ALFRED vintage；禁止把当前修订史当历史信息集 |
| 政策方向 | FEDFUNDS 的同比变化 | 月频 | 与政策利率水平使用同一历史信息集，不能另取今天修订值 |

标普总回报只作为未来结果变量。Shiller 月度总回报采用月均价格口径，必须保留来源定义；美元收益与人民币收益不可混用。

## 点时数据规则

1. 每条观测至少保留 `observation_date`、`release_date` 或 `available_at`、`vintage_date`、`value`、`source`。
2. 信号月末只可读取 `available_at <= signal_timestamp` 的最新观测。
3. 只有观测日期而没有发布时间的历史序列，标记为 `NON_PIT`，不得进入严格样本外测试。
4. ALFRED 的月末 vintage 列不自动等于该月最后一天投资者可获得的信息。必须逐列核对真实发布时间和 vintage 定义；如不能证明，降级为 `APPROX_PIT`。
5. 缺失值不插值、不前向填充跨越未发布期间、不以未来修订值回填过去。
6. 计算结果须同时保存输入版本、代码版本、参数、运行时间和 SHA256。

## 因子与分档计算约定

- 因子分位：仅在可用历史窗口达到 120 个有效月后计算；使用包含当月的滚动窗口，并采用 midrank 百分位。
- NFCI：按信号时点可获得的最近一期周值计算，不允许直接拿未来公布的周值。
- DFII10：对当月信号时点前已公布的日值计算月度统计量；聚合口径固定并记录。
- FEDFUNDS 水平：按当时已发布的月值计算；政策方向为同比变化，使用同一 PIT 数据版本。
- 综合分数：`0.30*CAPE_pct + 0.25*DFII10_pct + 0.25*NFCI_pct + 0.10*FEDFUNDS_pct + 0.10*policy_direction_score`。
- 历史分档：综合分数至少具备 36 个有效月后，按过去 36 个月（含当月）midrank 分位映射 Q1–Q5。因子分数与滚动历史分位必须分开显示。

## 样本外验证规则

- 先按时间切分训练集、验证集、测试集；不得随机打乱时间序列。
- 因子权重、阈值和参数只能在训练集确定；测试期不得调参。
- 未来 12/36/60 个月总回报从信号月之后开始，明确窗口是否重叠。
- 同时报告样本数、平均/中位累计收益、负收益比例、最大回撤、期限末未修复比例。
- 相关性报告 Spearman/Pearson、有效样本数及 3/6/12 个月区块 Bootstrap 置信区间。
- 对测试集不足、风险分档缺组或区块数量过少的情况明确标记“统计证据不足”，不得输出确定性预测结论。

## 发布门槛

以下条件全部通过才可将页面标记为“真实研究版”：

1. 五个因子的输入数据均有可核验的历史可用时点。
2. 每个原始文件有来源、覆盖审计、缺失/异常检查和 SHA256。
3. 生成真实 PIT 月度因子面板；所有输入字段均能追溯到具体 vintage。
4. 因子、综合分数、风险分档可从原始文件独立复算。
5. 样本外切分与 Bootstrap 可复现，且无未来信息泄漏。
6. 页面所有快照、表格、图表均由计算产物生成，不再硬编码示意结果。
7. CI 严格门禁通过；任一关键数据缺失则显示“未通过”，不以部分成功冒充完成。
